# 通用单选弹窗

2026-09-24。所有原下拉选项改为独立居中选择弹窗，两方向使用同一个 `SelectOptionDialog` 与 XML。

## 交互与视觉

- 当前值为蓝色描边、浅蓝底和单选圆点；点选新值立即生效并关闭。
- 重选当前值只关闭，不重复重启设备或写配置。取消、系统返回和点遮罩不提交。
- 标题与取消固定，选项区独立滚动；打开时定位当前项。空列表显示“暂无可选项，请返回页面刷新”。
- 白色圆角 12dp、内边距 24dp；宽度 `min(560dp, 可用窗口宽度 - 40dp)`，列表按可用高度约束，使弹窗通常不超过窗口高度的 80%。
- 标题 24sp，说明 16sp，选项及取消 18sp；选项最小高度 64dp、间隔 8dp；取消高度 52dp；遮罩黑色 40%。沿用应用字体和现有色板。
- 选择入口使用向右箭头，不再使用展开式向下箭头。

## 入口覆盖

| 页面 | 选项 |
| --- | --- |
| 相机 | 相机设备、分辨率 |
| 称重 | 串口 |
| 打印 | 打印机类型、型号/设备 |
| 商品学习 | 排序、学习状态筛选 |
| 系统维护 | 语言 |
| 旧系统设置 | SDK 对接通道 |

普通开关、已有分段切换、数值键盘和业务确认弹窗保持各自交互。

## 设计稿

- 统一源稿 [huoyan-retail.pen](huoyan-retail.pen)：顶部公共组件区保留横竖屏“通用单选弹窗”；10 模块包含当前选中项、无可选项、长列表滚动三个场景，横竖屏并排。
- 设备名与连接状态是设计示例。

## 实现

`app/src/main/java/cc/huoyan/retail/common/ui/SelectOptionDialog.java` 接收独立的显示文案和稳定值；参数复制进 Fragment arguments，避免打开后列表刷新导致位置错配。宿主初始化时注册 Fragment Result 监听，使弹窗重建后仍可回传。相机/串口/打印设备选中前再次核对可用性。

布局位于 `app/src/main/res/layout/dialog_select_option.xml` 与 `item_select_option.xml`。横竖屏共用布局，窗口宽度和列表最大高度按当前可用区域计算；列表之外不滚动。商品学习同时保存排序与筛选值，避免重建后与弹窗回显不一致。

设备回归见 `app/src/androidTest/java/cc/huoyan/retail/common/ui/SelectOptionDeviceTest.java`。
