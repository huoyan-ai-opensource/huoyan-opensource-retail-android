## 激活选模与模型切换（2026-10-16）

- 激活流程：手输或扫码提交有效激活码 → 关闭输入弹窗 → 打开「选择模型」自定义列表 → 点选模型后继续激活。取消、返回或点遮罩返回输入并保留本次激活码，不提交激活。新增画板位于 0,7160（横屏）及 1336,7160（竖屏）。
- 识别设置：当前模型与模型版本合并在同一卡片内，上下排列。横屏「切换模型」保留在「识别模型」标题旁；竖屏按钮移入卡片右侧，左侧展示名称和版本。切换独立于「保存配置」。模型使用动态名称，不再固定列出生鲜、零食、烘焙、小碗菜；默认页、允许删除已开启页及切换弹窗背景共六张横竖屏画板同步调整。
- 点击切换按钮打开项目自定义单选列表，回显当前项；点选其他模型后关闭列表并触发切换，点当前项只关闭，取消不提交。弹窗画板位于 8704,11080（横屏）及 10040,11080（竖屏）。
- 模型列表数量、名称、顺序均不固定；A／B／C 与版本号仅为设计占位。已对齐 SDK `queryLicenseModels` 动态列表与 `activate(activationCode, modelCode)`；切换无参查询当前设备模型；点选其他模型后，有证书激活序列号则直接重新激活，无序列号则复用激活码弹窗补输或扫码。补码取消不写入，确认保留所选 modelCode，连接变化要求重选。交互说明节点 IY5ZF / vFoWv 已同步保存。
- 读取列表、激活及切换期间使用 LoadingDialog 并防止重复提交；完成、失败或页面销毁时关闭。操作结果按真实回执通过 ToastEx success / error 提示；失败或无可选模型返回入口并可重试，不在卡片或列表内回显错误。
- 长名称换行、长列表滚动、取消按钮固定可达，页面内容随字体增长滚动。模型弹窗及合并后的横竖屏模型卡片已进行 130% 字体的画布检查；这不等同于 Android 设备验证。横竖屏共用交互说明位于 4352,20616。
