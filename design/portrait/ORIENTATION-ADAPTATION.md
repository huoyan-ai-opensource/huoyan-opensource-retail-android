# 横竖屏布局适配方案

横竖屏 XML 共用业务逻辑，布局按设备方向选择资源。

设计基准为 [统一设计稿](../huoyan-retail.pen)，页面节点与编排见 [设计索引](../DESIGN-INDEX.md)。本文识别页布局记录为早期实现基线，最新识别页设计以 [识别页调整](../RECOGNITION-20261013.md) 为准。竖屏画板为 540 × 960，用于表达比例，不应直接套作所有设备的 dp 尺寸。学习页沿用最新 `ProductLearningActivity` 的操作逻辑。

## 首页与导航

应用启动先进入功能首页。进入收银创建新的识别会话；返回首页结束当前清单，再次进入不恢复上一单。页面不展示“每次进入收银，开始新的识别”全局提示。

竖屏首页采用两列功能卡片，顺序与横屏一致：商品学习、相机设置、称重设置、打印设置、识别配置、SDK 连接、店铺信息、商品与识别库、系统维护。关于设备进入设备授权。

- 首页标题统一为“火眼识别”，图标复用应用图标 `@mipmap/ic_launcher`。
- 顶部导航与识别收银入口固定。
- 下方功能卡片独立纵向滚动。设计视口高 644，内容高 844，滚动范围 200；卡片宽 242、高 156，两列间隔 16。以上为画板尺寸。
- 稿中提供首页初始状态和“首页 · 滑动到底部”状态，末尾的系统维护入口可以滚动到达。
- 功能页左侧导航统一为“返回首页”。日志、更新与授权也可从系统维护进入。

## 页面布局

| 功能 | 横屏 | 竖屏 |
| --- | --- | --- |
| 识别收银 | 左侧预览列含导航和底栏，右侧结果贯穿全高 | 顶部导航、预览、称重与结果上下排列，结果清单滚动，底部操作固定 |
| 识别导航 | 导航仅占预览列宽度；左侧返回首页，右侧店名 | 导航占页面宽度；同样只有返回首页与店名 |
| 识别状态与版本 | 预览左上状态，右下版本 | 同样叠加在预览内，不放在导航栏 |
| 功能入口 | 首页九宫格 | 首页两列纵向滚动，无功能抽屉 |
| 设置与维护 | 相机等配置面板并排；打印、店铺和维护为单栏 | 单列内容，长内容滚动，操作保持可达 |
| 商品学习 | 商品与学习区左右分栏 | 商品列表在上，图片与预览在下，保留同屏学习操作 |

识别状态使用原有 `bg_grey_radius_2` 半透明底色（Android `#33FFFFFF`，20% 不透明度），圆角沿用原资源；版本号不加底色。保留文字与彩色状态灯，覆盖实时、暂停、锁定、无结果、未匹配、价格冲突及已打印状态。

设置页首个内容区距 64 高导航栏 16；稿中内容从 y=80 开始。独立页不显示收银清单提示。打印设置不显示测试小票预览，店铺信息不显示小票抬头预览。系统维护保留各维护入口，删除维护提示模块，退出应用为独立底部按钮。

设备授权去掉激活用途提示和内嵌激活码标题/输入框。保留激活按钮，点击打开现有 `ActivateCodeDialog`，支持手动输入、扫码和取消；复用原有激活通道。

相机设置从首页直接进入时须回显当前相机、已保存分辨率及镜像设置。配置回显独立于预览尺寸变化，首帧刷新连接状态，退出页面移除监听。

## Android 落地约定

同一个 APK、同一套 Activity 和业务逻辑，按系统窗口方向选择布局。C50D 使用横屏，NB55 使用竖屏，不按设备型号判断方向。设备运行中方向固定，本次不增加实时旋转处理或方向切换开关。

横屏使用 `layout-land/` 及默认布局，竖屏通过 35 份 `layout-port/` 资源调整分区和滚动方式：

```text
app/src/main/res/
├── layout/          # 共享布局与默认资源
├── layout-land/     # 已交付的横屏识别、学习及弹窗布局
├── layout-port/     # 竖屏首页、识别、学习、设置及弹窗
└── values/          # 共享文案、颜色、尺寸
```

- `HomeActivity` 负责首页入口，`MainActivity` 负责收银，`SettingsPageActivity` 按需创建当前配置 Fragment，避免后台页抢占外设。
- 业务控件保持相同 ID、兼容 View 类型和监听器；`PricingMode`、`PricingGate`、`CartCalculator`、SDK 及打印逻辑共用。
- 竖屏预览完整居中适配，图像、框、标记和触摸命中使用同一转换；横屏保留原有高度适配。不因屏幕竖向旋转 UVC 图像。
- 数量/重量弹窗按可用宽高布局，保留取消与确定；激活输入适配软键盘。
- 学习页需调整 `resizeColumns()`、列表列数及图片网格，避免 Java 覆盖竖屏上下布局。拍照成功即学习生效，保存提交反馈并刷新图片。
- 新增竖屏尺寸使用明确 dp/sp，避免误套 `values-sw720dp` 历史倍增映射。触摸区域至少 48dp，金额、长商品名及键盘显示时的按钮保持可读可达。

## 验收边界

布局与交互回归使用 `PortraitLayoutDeviceTest`、`LandscapeNavigationDeviceTest`、`LandscapeDialogsDeviceTest` 和 `SelectOptionDeviceTest`，测试源码位于 `app/src/androidTest/java/cc/huoyan/retail/` 对应业务包。

相机、串口秤和打印机链路需在具备相应外设的真机单独验证；页面布局通过不代表外设链路通过。构建及测试入口见 [代码目录说明](../../docs/code-structure.md#验证)。
