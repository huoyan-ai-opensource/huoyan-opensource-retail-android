# NB55 横屏适配

## 资源选择

以横屏窗口可用宽度为准，不按屏幕英寸或设备型号判断。

- `layout-land`：不足 1100dp 的紧凑横屏。
- `layout-w1100dp-land`：至少 1100dp，保留本次修改前的 18 份页面及弹窗布局。
- 首页两列统一使用 28:72 比例；功能卡片在紧凑横屏中图标居上，在宽横屏中恢复原有横向排列。
- 竖屏继续使用原有 `layout-port`。商品表单的输入法窗口调整仅在紧凑横屏生效。

## 修改范围

| 页面 | 紧凑横屏处理 |
| --- | --- |
| 首页 | 识别收银与右侧功能区按比例分配宽度 |
| 相机、电子秤、打印、识别、门店、商品、维护、授权设置 | 两侧内容独立滚动，收紧留白，部分标签和值纵向排列 |
| SDK 连接 | 地址与设备列表按比例分配宽度 |
| 商品管理 | 列表与表头同步缩窄固定列，为名称保留空间 |
| 商品学习 | 底部操作使用完整宽度 |
| 收银 | 汇总与操作按钮分行 |
| 数量、重量输入 | 压缩弹窗留白，保留可触摸按键 |
| 搜索、改品 | 合并顶部查询工具栏，为商品列表及键盘留出高度 |
| 新增、编辑商品 | 内容可滚动，固定确认区；真实输入法显示后将焦点输入框滚入可见区域 |

业务流程、计价和相机坐标变换未修改。

## 2026-10-10 验证

- NB55：800×1280、240dpi、字体缩放 1.0；横屏应用宽度约 805dp。主要页面、九个设置页面与常用弹窗的可见性和滚动终点设备测试通过，并检查运行截图。
- C50D：1920×1080、240dpi，横屏约 1280dp；同一组页面与弹窗设备测试通过。18 份宽屏布局与修改前资源逐字节一致。
- NB55 商品表单：真实 Gboard 弹出后，商品名称输入框和确认按钮完整可见，专项设备测试通过。
- 使用 JBR 17 构建 Debug 和 AndroidTest APK 成功。
- NB55 竖屏页面与固定操作区回归通过；SDK 页按实际列表/空态结构检查。

测试只打开、滚动和取消页面或弹窗，未提交商品或设备配置。硬件通信及识别准确率不属于此次布局验收。日志页未注册到 Manifest，仅静态检查；扫码及其余辅助弹窗未逐一实机覆盖。此次未编辑 `.pen` 设计稿。

设备测试入口为 `CompactLandscapeDeviceTest`；C50D 运行主要页面测试时传 `rotation=0`，NB55 默认 `rotation=1`。真实输入法专项仅在 API 30 及以上、小屏设备执行。
