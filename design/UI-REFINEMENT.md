## 状态色与间距调整（2026-10-10）

### SDK 启动等待态补充

启动闪烁与版本延迟修正：等待态最少展示 600ms，较长的初始化仍按真实完成时间退出；页面离开后取消延迟回显。暂不可用的授权快照不再覆盖明确授权，避免入口颜色来回切换。版本通过独立线程在连接后立即查询，不再等待云接口和 5 秒状态轮询，空状态快照不清空已显示版本。

本轮 422 项单元测试、C50D 和 NB55 各 3 项首页设备检查通过，Lint 0 错误、503 项既有告警。保留数据安装最新 APK 后，C50D 真实冷启动从首次启动观察日志到版本返回约 0.58 秒。用户确认 NB55 的旧 SDK 不返回版本号，保留“SDK —”属于预期兼容行为，不作为查询性能失败。证据位于 `app/build/reports/ui-startup-smooth-20261010/`。本轮调整状态时序，未改设计样式。

后续修正：用户反馈真实启动仍提前显示收银入口。原实现只等待通道连接，并在读到版本后停止 SDK 启动观察，不能代表初始化完成。现将卡片初始化等待与页脚连接提示分开，卡片首帧默认等待，通过 SdkStartupController 的真实状态回调更新；NOT_INIT、INITIALIZING、MODEL_PREPARING 等阶段继续等待，版本查询不再停止初始化观察。回调按页面代次丢弃，明确未激活后恢复黄色入口。此规则替代下文最初的“连接后恢复”判定。

修正后 420 项单元测试、两台设备各 3 项首页测试通过，构建及 Lint 通过。最新 APK 保留数据安装至 C50D 和 NB55；实际重启客户端与本机 SDK 后，两台均在 NOT_ACTIVATED 回执后退出等待。两台当前均未激活，完整模型初始化的长等待链路由状态时序测试覆盖，未宣称在已激活设备复现。证据见 `app/build/reports/ui-startup-fix-20261010/`。视觉样式未变。

按用户补充要求，首页收银卡片增加灰蓝色等待态（卡片 `#66758B`，按钮 `#536176`），文字与图标为白色，提示“正在连接识别服务，请稍候”，按钮显示“SDK 启动中…”。等待期间禁用入口并隐藏箭头；SDK 缺失优先显示安装，连接后恢复授权对应入口。此状态沿用现有通道连接观察，不等待模型初始化。

横屏节点 `Z8leu`、竖屏节点 `jGQhb` 已检查并在编辑器保存。JBR 17 构建、418 项单元测试通过，Lint 0 错误、503 项告警。C50D 与 NB55 各 3 项首页设备测试通过，覆盖等待期间阻止跳转、旧授权快照不能覆盖等待态、连接完成后恢复入口及原激活弹窗。最新 APK 已保留数据安装至两台设备。等待态截图使用视图夹具，截图与原始输出位于 `app/build/reports/ui-startup-20261010/`。
