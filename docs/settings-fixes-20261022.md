## 画面变化启动整轮识别与事件调度（2026-10-23）

阈值只决定一轮识别何时启动。超过阈值后持续消费相机的新帧，画面静止不再阻断后续确认；空识别回执也不会重新关闭本轮。沿用现有三次一致或有效结果三秒超时的锁定条件。锁定后停止工作线程调度，重新识别、页面恢复及相机代次变化按会话边界重新建立基线。称重流程绕过画面变化门控。

`RecognitionLoop` 删除定时执行器和 200 ms 重试，由相机发布新帧、SDK 就绪和业务恢复主动唤醒。请求始终在同一工作线程串行执行；在途通知合并，只取最新帧；所有模式都不重复发送已消费的同一帧。SDK 未就绪时不提前消费待识别帧。停止或报错后，相机通知不能自行重启，旧代次回执继续丢弃。

验证：

- 488 项单元测试通过，0 失败、0 错误。覆盖全部五档一次变化后空回执及静止帧继续完成三次确认、无通知不轮询、在途通知合并、IDLE 返回期间通知不丢失、停止与重启串行及旧回执失效。
- Debug APK、androidTest APK 构建通过；Lint 0 错误。
- C50D 原生 1920×1080、240 dpi 通过 `FrameGateDeviceTest`。取真实 NV21 帧后只修改哈希采样点受控回放，最低档距离 0、8 不启动，9 启动；启动后相同画面的新帧继续取得真实 SDK 回执，共三次请求（一次触发、两次静止续发）。同时验证未就绪帧不提前消费及就绪事件唤醒。
- 真机测试中的三次一致锁定使用固定识别回执，验证页面锁定、调度停止及下一轮复位；它不代表自然放盘或现场商品识别准确率验证。
