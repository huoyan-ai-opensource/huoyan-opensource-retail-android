# 常见问题与排查

第一次运行请先按[快速开始](../QUICKSTART.md)操作。开发接入错误码和线程约束见 [SDK 指南](../huoyan-sdk-client/INTEGRATION_GUIDE.md#error-handling)。排查时保留失败时间、错误码和 `reason`，不要只记录“不能用”。

## 找不到下载或激活入口

App 成品从 [GitHub Releases](https://github.com/huoyan-ai-opensource/huoyan-opensource-retail-android/releases)获取；尚无附件时按[构建指南](build.md)构建。SDK 可由首页「系统维护」→「获取 SDK」下载。SDK、试用、包名登记、账号和模型范围通过[火眼官网](https://www.huoyan.cc)联系项目方确认。开源 App 源码不包含可任意使用的云端账号或模型授权。

## 安装 SDK 或 App 失败

| 现象 | 处理方向 |
| --- | --- |
| 禁止安装未知应用 | Android 8.0+ 在系统中为当前安装来源授权，再返回完成安装；有设备管理策略时联系管理员 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 已装版本和新 APK 签名不同。核对 Debug、公开实验 Release 和正式签名；先确认备份与数据保留方案，不直接卸载 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 目标 `versionCode` 较低，选择正确升级包，不把降级作为常规升级 |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | APK 或依赖原生库不支持设备 ABI，确认设备芯片和交付包 |
| 安装器无法打开 | 系统没有可用安装组件或厂商策略限制，尝试管理员允许的部署方式 |
| 下载后仍提示未安装 SDK | 确认真正完成系统安装，安装包名为 `cc.huoyan`，而非仅完成 APK 下载 |

默认实验签名公开且限制使用范围，见[签名说明](../signing/README.md)。修改包名或重签 SDK 可能影响接入和授权，不作为排障捷径。

## SDK 已安装但连不上

先看「SDK 连接」保存的是本机还是局域网：

- **本机 AIDL**：确认 SDK 包名、App 包名登记及配套版本。Android API 24～26 使用 WS，不能按 API 27+ 的 AIDL 路径处理。
- **本机 WS**：确认 SDK 服务正在运行，地址为 `127.0.0.1`，默认端口 `18086`、路径 `/ws`。
- **远端 WS**：填写 SDK 所在设备的实际 IPv4 地址；`127.0.0.1` 永远指客户端自己。检查 Wi-Fi AP 隔离、VLAN、VPN、防火墙和 SDK 的网络访问范围。页面「测试」成功后仍需保存配置。

只使用可信局域网，不以关闭鉴权、公开端口或修改私有网络配置的方式绕过接入限制。远端部署不要求客户端设备再装本机 SDK，但 SDK 设备仍需满足激活和模型条件。

## 已连接、初始化或激活成功，为什么还不能识别

这几个状态不是同一件事。连接只确认通道，初始化和激活返回成功也不保证模型已经准备完成。查看「关于设备」及实际状态：

1. 先核对最新查询是否成功，不能沿用上一次的成功状态。
2. `MODEL_PREPARING` 时等待下载与加载，下载 100% 后仍可能尚未就绪。
3. 以 `SdkStatus.modelReady(status)` 为识别、学习准入条件；仅看到 `READY` 或版本号不足以判断。
4. 证书过期、无效、密钥丢失、模型不匹配及后端错误，保留准确错误码和原因，按对应问题处理。

激活回执未知时先查询授权和状态，不因超时连续重提激活、学习或删除。SDK 版本、模型版本和证书有效期分别查看，不能相互替代。

已激活设备查询模型却提示未激活时，不应直接清除证书或重新激活。还要核对模型查询接口是否已部署、请求方法和版本是否匹配；旧部署的路由 404 曾被下层映射为授权错误。保留真实错误和服务端请求时间，请项目方区分接口不可用与授权不可用。

## 断网以后还能使用吗

首次激活及模型下载需要网络。已经准备好的本地 SDK 处于 `OFFLINE` 时，若最新有效状态确认 `modelReady=true`、`certificateValid=true` 且 `keyLost` 不为 true，本地识别和学习可继续，不必等联网回到 `READY`。

激活、切换模型、反馈、上传、同步，以及开启云端服务后的商品写入仍由各自云端回执决定。离线不等于这些请求成功，也不应自动关闭云端服务。证书过期、密钥丢失或状态查询失败不能用“离线可用”绕过。

## 必须绑定门店或开启云服务吗

单机识别学习不要求先绑定门店。店铺小票信息、门店绑定和商品云托管是不同功能，需要云服务时才按交付流程配置。

当前云服务开启确认明确提示开启后不可关闭。开启前确认设备绑定到正确门店及业务需求；不要在生产设备为测试随意开启。云服务开启后的商品操作受云端可用性影响。

门店名称、地址和电话是绑定成功时保存的资料快照，后台修改后不会仅因页面重新打开就自动更新；需要按当前绑定流程重新取得资料。空地址和电话应显示未填写，不能用门店 ID 代替。

## 相机、秤、打印机不工作

先阅读[硬件支持范围](hardware.md)。相机设置要区分「USB 相机」与「原生相机」，确认相机权限、设备和正确分辨率，并避免被其他 App 占用；USB 模式另查 USB 授权、Host/OTG 及供电。秤当前是顶尖 Aclas 驱动与串口接入，不是所有串口秤通用；无端口或打开失败要核对厂商驱动和系统权限。

打印当前为通用 USB ESC/POS，内置私有打印服务和串口打印机未包含。USB 可枚举不等于协议兼容。发送失败后先观察是否已经出纸，避免直接重试打印重复票；详见[打印文档](printer-escpos.md)。无外设体验时关闭对应模块，使用计件商品。

## 学习了但识别不到，或选错商品

确认当前模型场景与商品一致、学习请求成功且样本已列出，PLU 和选中商品正确。检查画面焦点、商品大小、遮挡、光照和取景范围，适当补充不同角度样本。不要把不同商品拍到同一个 PLU，也不要用阈值调整掩盖相机、授权或模型错误。

切换不同模型前确认识别库是否兼容；备份与恢复应对应正确模型。不要用历史验收记录中的内网地址、测试模型或数据库 ID 作为自己的配置。

## 学习或结算成功，为什么云端没有图片和反馈

本地样本学习、确认结果、USB 字节发送、图片上传与云端落库是不同阶段。页面确认或打印成功不能证明反馈上传成功。学习小图由 SDK 壳后台上传并登记，客户端不再另发学习 feedback；已触发的学习小图上传失败不会由客户端持久化待办补传，不能仅恢复网络或补齐服务器配置后等待旧图自动重传。

反馈排查先确认 `UPLOAD` 图片上传阶段，再核对 `SUBMIT` 反馈提交阶段。`upload_token` 返回 500 时，应让服务端检查 COS 配置和请求日志，不能让客户端填写服务端 COS 密钥；图片上传失败时不应把尚未执行的 item/feedback 落库当成成功。需要重做业务验证时，使用隔离测试数据，从 App 真实操作重新执行，并独立核对后端结果。

## PLU 与商品 ID 有什么区别

学习与识别分类 `clazz` 使用 PLU 原值字符串，保留大小写和前导零。`A001`、`a001`、`001` 和 `1` 是不同分类，不转成数字，也不使用商品 ID 或样本 UID 代替。SDK 分类接口支持 1～50 位 ASCII 字母和数字，当前 App 新增商品表单限制为 1～32 位；这两个限制针对不同入口。

## 识别参数为什么没有立即生效

相机选择和部分开关即时保存，数值识别参数及触发灵敏度先保留草稿，需点击「保存配置」；恢复默认只填回表单，不等于已经保存。离开时按页面提示保存或放弃。开启称重时，画面变化识别开关禁用但保留偏好。

画面变化灵敏度 1～5 档从很低到很高，对应亮度哈希距离阈值 8、6、4、2、1，严格超过阈值才启动一轮识别；首帧只建立基线。一旦启动，后续静止的新帧仍参与结果确认，直至锁定；称重模式不使用这项画面门控。该开关不是模型准确率或置信度开关。

## 如何收集问题信息

记录出现问题的时间、操作步骤及页面提示。当前 App 不提供日志文件浏览入口，开发设备可通过 ADB 收集本次操作附近的 Logcat：

```shell
adb logcat -v threadtime
```

若要保存文件，在自己的诊断目录执行 `adb logcat -d -v threadtime > retail-logcat.txt`；不要把完整日志直接提交到仓库。Release 不保证包含 Debug 的 `[Biz]` / `[Toast]` 打点，缺少这些打点不代表请求未执行。

普通问题提交到 [GitHub Issues](https://github.com/huoyan-ai-opensource/huoyan-opensource-retail-android/issues)，附 App/JAR/SDK 版本、Android/API、芯片和 ABI、AIDL/WS、本机/远端、复现步骤、期望和实际结果，以及已脱敏的短日志。遮挡员工/客户数据、账号、激活码、序列号、令牌、密钥和私有服务地址。授权或安全问题按[安全反馈说明](../SECURITY.md)走私密渠道。
