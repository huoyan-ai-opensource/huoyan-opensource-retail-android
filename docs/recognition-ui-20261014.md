顶部为净重、皮重、总重量三张卡片；竖屏独占一行。净重圆点响应稳定、不稳定和异常，断开连接立即撤销旧读数。识别状态沿用项目样式叠加在预览左上角，点击查询真实 SDK 状态。

结果列表标题移除，四角水印不占条目高度。商品售价突出显示；底部仅保留种类、数量、总价。横屏按钮组与汇总整体靠右，竖屏上下排列在同一白色卡片内。等待时播放修复腿部连接的端盘扫描 GIF，出现结果停止播放，系统关闭动画时使用静态图。

称重键盘输入 kg，最多三位小数；去皮与置零独立，未连接、过期或不稳定读数拒绝提交。设备回读确认后才报告成功，3 秒未确认则失败并保留输入。SDK 自检支持刷新、原始错误和滚动正文；未知字段保留 `—`。

三击版本号与系统返回统一检查本地退出密码。维护页使用项目 `LandscapeSwitch`、`land_switch_thumb` 和 `land_switch_track`；首次开启只有两次密码一致并保存成功后才启用，取消保持关闭。密码存储随机盐派生摘要，不保存明文。

相机与 SDK 状态来自 C50D 实机；商品行/金额断言使用仅在内存中的测试商品，不写商品库。窗口模拟不代表另一型号设备验收。测试在提交称重命令前断开秤连接，没有对放置商品的实物秤执行去皮或置零；真实去皮回执的单位和物理置零效果仍需空秤现场确认。未执行打印、提交或推送。

- 称重弹窗顶部内边距收至 8dp；预置皮重提示移至标题下方，清空按钮所在行与输入框间保留 8dp。退格键复用现有图标，底色与数字键统一。

### 键盘等高、统一间距与 SDK 商品查询修复

- 横屏称重键盘与左侧读数、预置皮重两个模块整体上下对齐；设置密码键盘与左侧说明、两次密码输入区域上下对齐。键帽随行高伸缩，避免固定高度导致底部圆角被裁切；竖屏继续上下排列。
- 设置页共用 `ui_spacing.xml`：宽横屏 / 竖屏 / 紧凑横屏的横向外边距分别为 32 / 20 / 16dp，卡片内边距为 24 / 20 / 16dp。维护页退出保护内边距收为 12dp、内容间距 8dp。其他页面相同外边距改为引用公共尺寸，保留原有更紧凑的业务区域。
- SDK 壳已有 3 件同门店商品，`account_id` 为空，被原账号与门店双重精确过滤排除。已在 SDK 壳的 SQL 与内存查询中统一修复：门店精确匹配时允许缺省账号；明确冲突账号、其他门店仍不放行。宿主继续只从 SDK 查询商品。
- 检查客户端分页、PLU 精确查询、新建、按 SDK goods_id 更新和删除及失败回执。删除统一交给 SDK 壳处理商品和 SDK 关联资料，宿主仅清理自己的学习资料；移除删除前额外按 PLU 遗忘类别的旧步骤。冷启动改为连接建立后加载目录，目录读取不再以模型就绪为条件。
- JBR 17 构建与 Lint 通过，客户端 466 项单测通过；SDK 商品相关 229 项单测、6 项真实 SQLite 设备测试通过。SDK 壳与客户端已覆盖安装到 C50D，真实商品管理页可见 3 件商品。
