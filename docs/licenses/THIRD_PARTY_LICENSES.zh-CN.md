### 概述

此软件包包含实现 JPEG 图像编码、解码和转码的 C 软件。JPEG（读作 “jay-peg”）是一种面向全彩色和灰度图像的标准化压缩方法。JPEG 擅长压缩摄影图像，以及相邻像素的颜色和亮度平滑变化的其他图像。具有锐利线条或其他突变特征的图像可能无法很好地压缩；为避免可见压缩伪影，可能需要使用较高 JPEG 质量。

JPEG 是有损的，意味着输出像素不一定与输入像素完全相同。但对摄影内容和其他“平滑”图像，可以在没有可见压缩伪影的情况下取得很好的压缩率；如果愿意通过降低压缩器的“质量”设置来牺牲图像质量，则可以取得极高压缩率。

本软件实现 JPEG 基线、扩展顺序和渐进压缩过程。软件设计为支持这些过程的全部变体，尽管部分不常见参数设置尚未实现。软件没有为标准定义的分层或无损过程提供支持。

我们提供一组读写 JPEG 图像文件的库例程，以及两个示例应用 `cjpeg`、`djpeg`；它们使用本库在 JPEG 与其他常见图像文件格式之间转换。本库旨在被其他应用复用。

为了支持文件转换和查看软件，我们加入了超出基本 JPEG 编码/解码能力的大量功能。例如，颜色量化模块严格来说不是 JPEG 解码的一部分，但对于输出到使用颜色映射的文件格式或显示器至关重要。如果具体应用不需要这些额外功能，可在编译时将其从库中移除。

我们还提供 `jpegtran`，用于在不同 JPEG 过程之间进行无损转码；以及 `rdjpgcom` 和 `wrjpgcom`，两个用于在 JFIF 文件中插入和提取文本注释的简单应用。

软件设计重点是可移植性和灵活性，同时保证足够实用的速度。特别地，本软件不是 JPEG 教程；入门资料见参考资料一节。我们的目标是可靠、可移植、可用于工业环境的代码。我们不声称软件的每一方面都已达到此目标，但一直在为此努力。

### 参考资料

在尝试理解 JPEG 软件内部机制前，建议阅读以下一份或多份资料。

JPEG 压缩算法最好的简短技术介绍是：

> Wallace, Gregory K. “The JPEG Still Picture Compression Standard”, Communications of the ACM，1991 年 4 月，第 34 卷第 4 期，第 30–44 页。

该期相邻文章讨论 MPEG 动态图像压缩、JPEG 应用及相关主题。如果无法取得该期 CACM，可从 http://www.ijg.org/files/Wallace.JPEG.pdf 下载 Wallace 文章修订版的 PDF。该文件实际是后来发表于 IEEE Transactions on Consumer Electronics 的文章预印本，省略了 CACM 版本的示例图像，但包含勘误和新增内容。注意：Wallace 文章版权归 ACM 和 IEEE 所有，不得用于商业目的。

关于 JPEG 技术性较弱、讲解较平缓的介绍，可阅读 Mark Nelson 和 Jean-loup Gailly 所著的 *The Data Compression Book*，M&T Books（纽约）出版，第 2 版，1996 年，ISBN 1-55851-434-1。该书对包括 JPEG 在内的多种压缩方法提供了良好解释和 C 示例代码。如果您熟悉 C 代码，但不太了解数据压缩，此书是很好的资料。书中的 JPEG 示例代码还远未达到工业实用程度；当您准备研究完整实现时，本软件就在这里。

原文认为当时最好的 JPEG 描述是 William B. Pennebaker 和 Joan L. Mitchell 的教材 *JPEG Still Image Data Compression Standard*，Van Nostrand Reinhold 出版，1993 年，ISBN 0-442-01272-1，价格 59.95 美元，共 638 页。该书包含 ISO JPEG 标准的完整文本，即 DIS 10918-1 和 DIS 10918-2 草案。

原始 JPEG 标准分为两部分：第 1 部分是实际规范，第 2 部分是符合性测试方法。第 1 部分题为 “Digital Compression and Coding of Continuous-tone Still Images, Part 1: Requirements and guidelines”，文档编号为 ISO/IEC IS 10918-1、ITU-T T.81；第 2 部分题为 “Digital Compression and Coding of Continuous-tone Still Images, Part 2: Compliance testing”，文档编号为 ISO/IEC IS 10918-2、ITU-T T.83。

JPEG 标准未规定可互换文件格式的全部细节。对于这些未规定细节，我们遵循 JFIF 1.02 版约定。JFIF 第 1 版已被采纳为 ISO/IEC 10918-5（2013 年 5 月）及 ITU-T T.871 建议（2011 年 5 月），题为 “Information technology - Digital compression and coding of continuous-tone still images: JPEG File Interchange Format (JFIF)”。可从 https://www.iso.org/standard/54989.html 和 http://www.itu.int/rec/T-REC-T.871 免费下载 PDF；较早的 JFIF 1.02 规范 PDF 位于 http://www.w3.org/Graphics/JPEG/jfif3.pdf。

TIFF 6.0 文件格式规范可从 http://mirrors.ctan.org/graphics/tiff/TIFF6.ps.gz 取得。1992 年 6 月 3 日的 TIFF 6.0 规范中，JPEG 集成方案存在若干严重问题。IJG 不建议使用该 TIFF 6.0 设计，即 TIFF Compression tag 6；建议改用 TIFF Technical Note #2 提出的 JPEG 设计，即 Compression tag 7。该技术说明可从 http://www.ijg.org/files/ 取得。原文预期下一版 TIFF 规范会用该说明的设计替代 6.0 的 JPEG 设计。尽管 IJG 自身代码不支持 TIFF/JPEG，但自由软件 libtiff 使用本库，依该技术说明实现 TIFF/JPEG。

### 文件格式兼容性

本软件实现 ITU T.81 / ISO/IEC 10918，以及 ITU T.871 / ISO/IEC 10918-5（JPEG 文件交换格式，见参考资料）中的部分扩展。日常所说的“JPEG 图像”或“JPEG 文件”，通常指 JFIF 或其子集；但另有名称含 JPEG、却与基于 DCT 的 JPEG 标准或 JFIF 不兼容的格式，例如 JPEG 2000、JPEG XR。因此，本软件不支持这些格式。开发本自由软件最初的原因之一，就是推动 JPEG 文件统一到共同、可互操作的格式标准。

JFIF 是一种最简或“低端”表示。需要记录大量图像附加数据的“高端”应用，可以使用 TIFF/JPEG，即经 TIFF Technical Note #2 修改的 TIFF 6.0。
