# 设备与外设

本页描述当前代码的接入范围及已有验收依据，不代表所有 Android 设备或同协议产品都已验证。首次部署先按 [快速开始](../QUICKSTART.md)完成一件商品的学习和识别，再启用秤及打印。

## Android 与 SDK 设备

| 项目 | 当前范围 | 部署时需要确认 |
| --- | --- | --- |
| 客户端系统 | Android API 24（Android 7.0）及以上 | 当前构建 targetSdk 为 28；最低 API 可安装不等于每台设备的 USB、串口和系统策略兼容 |
| 本机 SDK 通信 | API 27 及以上可选 AIDL；API 24～26 使用本机 WS | SDK APK 包名 `cc.huoyan`、客户端包名已登记，SDK 和 JAR 配套 |
| 局域网 SDK 通信 | WS 默认 `ws://<SDK设备IP>:18086/ws` | 同网段可达、无 AP 隔离、设备防火墙允许，SDK 部署允许局域网访问 |
| SDK 推理芯片与 ABI | 由所交付 SDK APK 和模型决定 | 不应仅凭客户端 `minSdk` 或编译 ABI 列表推断 SDK 支持芯片 |
| 界面 | 有横屏、竖屏及不同窗口尺寸资源 | 真机字体、系统栏及厂商窗口策略仍需实测 |

客户端包含 ARM 版 Aclas 秤原生库（`armeabi-v7a`、`arm64-v8a`）。构建脚本中 CMake 声明的 x86/x86_64 不表示这些供应商原生库或本机 AI SDK 支持模拟器。普通手机或模拟器可用于页面与纯业务逻辑验证；不连接 SDK 时不能学习或识别，不接真实外设时也不能证明称重、打印可用。远端 WS 可把客户端与 SDK 部署在不同设备，但远端 SDK 仍需要相应硬件和授权。

## 相机

当前相机入口提供两种模式：「USB 相机」使用 UVCAndroid，「原生相机」使用 Android Camera2。选择类型后枚举该类型的设备，不会在失败时自动切到另一类型。

USB 相机需要 USB Host/OTG 能力、足够供电及系统 USB 访问权限；标准 UVC 标识也不能保证所有分辨率、格式和固件可用。原生相机要求厂商通过 Camera2 正常暴露相机设备和输出尺寸，并需要相机权限。

在首页「相机设置」选择相机类型、设备和分辨率，观察预览，核对旋转、镜像、对焦、曝光、商品取景和检测框位置。分辨率先使用设备可稳定输出的较低档位；确认画面清楚后再按实际需求调整。不要同时由扫码工具、厂商相机应用或另一个客户端占用同一相机。

厂商私有相机接口或未通过系统 Camera2 暴露的 CSI 摄像头需要另外适配。代码包含 Camera2 不等于每个系统相机已完成实机验证，实际设备均应检查取景和识别链路。

## 顶尖 Aclas 秤

当前秤接入为 `AclasDriverSdk.jar` / `libAclasArmPos.so`，由 `AclasScaleManager` 枚举供应商可用串口。它不是任意串口秤通用协议，也不是蓝牙秤或 USB 转串口设备的自动适配。

进入「称重设置」，打开串口列表时自动枚举可用端口；选择真实秤体端口并启动称重测试，依次确认：

1. 空秤归零与单位正确，读数能稳定。
2. 放置已知重量，读数及稳定标志符合设备说明。
3. 如使用去皮，确认净重和皮重；不在业务中随意尝试未确认的串口。
4. 串口选中后即时保存；回到收银，再核对一次重量及计价。

串口权限受厂商系统镜像和供应商驱动控制。Android 相机或存储权限不能解决 `/dev/` 设备节点访问问题；页面无法枚举或打开时，先让设备厂商确认端口及权限，不应盲目套用别的机型串口路径或修改系统权限。

没有秤时关闭称重模块，使用计件商品。关闭称重模块后，称重商品会被业务校验拦截。

## USB ESC/POS 打印机

当前支持 USB Printer Class（class 7、protocol 1/2、alternate setting 0、Bulk OUT）的 ESC/POS 小票机，支持 58mm/80mm 纸宽选择。系统 USB 授权后才可传输数据；页面中选择实际设备，先连接测试再打印测试。

已有项目记录：C50D 上 BTP-N90LF（VID:PID `154F:1300`）58mm 小票由使用者确认可完整打印。80mm 及其他机型仍需要各自纸面验证。USB 能枚举不等于支持 ESC/POS，也不保证切刀、条码、走纸和纸宽配置一致。

内置厂商打印机服务、USB 转串口、主板串口、私有 USB 协议和标签打印协议当前不在通用实现范围。发送成功只代表字节已经发送，不代表机械出纸完成；失败后先观察纸张，避免自动补打产生重复小票。协议和测试入口见 [USB ESC/POS 小票打印](printer-escpos.md)。

## 权限与连接核对

| 提示或现象 | 先核对 |
| --- | --- |
| 相机画面为空 | 选择的相机类型、CAMERA 权限、分辨率、其他 App 占用；USB 相机另查 USB 授权、Host/OTG 和电源 |
| 没有秤串口或不能打开 | 供应商支持、实际端口、系统节点权限及 ARM 原生库 |
| 打印设备不可选 | USB Printer Class、数据线、供电、USB 授权及打印机指令模式 |
| SDK 安装器打不开 | Android 安装器、未知来源授权、MDM/厂商安装限制 |
| SDK 可见但不能识别 | 包名登记、连接、证书、模型就绪和芯片兼容；不能只检查 USB |
| 局域网连接失败 | 实际 IP、18086 端口、网络隔离、防火墙、SDK 访问范围 |

## 添加新的设备验证记录

反馈设备兼容问题时提供设备型号、Android/API、芯片、ABI、App/JAR/SDK 版本、外设型号和连接方式。记录具体通过的流程（预览、学习、识别、计价、出纸），不要将“安装成功”记成整机通过。请勿在公开记录附带激活码、账号、完整设备序列号或客户数据。

完整验收方式见[测试指南](testing.md)。旧版本的设备联调记录可从 Git 历史追溯；其中的内网服务器和测试设备不属于公共服务或推荐配置。
