## 构建与测试

使用 JBR 17。客户端 `assembleDebug`、`assembleDebugAndroidTest`、`testDebugUnitTest`、`lintDebug` 通过；458 项单元测试无失败。Lint 通过不表示既有警告全部清理。

SDK 壳源码联编与本地 AAR 构建通过，全量单测 1379 项、跳过 10 项、失败 0；core 全量单测 730 项无失败，release AAR 构建通过。SDK 壳 WebSocket 启停测试曾失败一次，单项及随后全量复跑通过，未改动该模块。

C50D（DEVICE_SERIAL）覆盖安装客户端及 SDK 壳，保留数据。原窗口 1920×1080、density 240。横屏 6 项设备测试通过；另以 1080×1920 临时窗口确认实际竖屏资源，竖屏界面、小票和密码共 5 项通过。最终包另回跑收银计时与清空重建 2 项通过。结束后恢复 1920×1080，无 density override。竖屏是同一设备窗口模拟，不代表其他硬件验收。

证据位于 `app/build/outputs/integration-review-20261020/`，包括横竖屏相机、选择弹窗、商品皮重、串口、小票位图和测试输出。设计总稿 `design/huoyan-retail.pen` 已通过 Pencil 更新并保存，索引同步。

## 联调边界

- C50D 当前已激活。未激活删除用受控测试验证，未清除真实证书或商品。仍需一台未激活设备复核端到端创建／删除。
- 本轮未操作实体打印机出纸、未向秤发送置零／去皮命令；小票验证为真实渲染位图，10 秒计时使用打印成功状态夹具。
- 已验证隐式绑定拉起心跳服务，未核对服务端连续心跳记录；item 数字类型验证使用 HTTP 测试服务，未进行真实云端写入。
- core 的本地新 AAR 已接入壳包，但没有发布新的 core Release。正式 CI 发布前需要更新 core 发布件及壳取件锁，详见相邻壳仓库 `docs/integration-fixes-20261020.md`。
